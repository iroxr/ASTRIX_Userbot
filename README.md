# منصة بوت تيليجرام (Userbot)

هيكل متكيّف مبني على مكتبة Telethon، يتميّز بما يلي:

- **نظام إضافات**: كل ملف في `plugins/` إضافة مستقلة، وتُحمَّل وتُعطَّل وتُثبَّت أثناء التشغيل.
- **أوامر تتسجّل تلقائيًا**: عند إضافة أمر جديد يظهر في قائمة الأوامر دون أي إعداد.
- **قائمة مصنّفة ومرتّبة**: `.الاوامر` تعرض الأقسام، و`.اوامر الذاتية` تعرض أوامر القسم.
- **قاعدة البيانات هي مستودع GitHub**: كل مجموعة بيانات ملف JSON في فرع مخصّص (الافتراضي `database`)، ولا حاجة إلى أي قاعدة بيانات تقليدية.
- **واجهة بالعربية الفصحى** في جميع الرسائل والأوامر.

## التثبيت

```bash
pip install -r requirements.txt
cp .env.example .env        # ثم املأ القيم
python tools/generate_session.py   # لتوليد TG_SESSION
python main.py
```

المتغيرات المطلوبة في `.env`:

| المتغير | الوصف |
|---|---|
| `TG_API_ID` / `TG_API_HASH` | من https://my.telegram.org |
| `TG_SESSION` | نص الجلسة الناتج عن `tools/generate_session.py` |
| `GITHUB_TOKEN` | رمز Fine-grained بصلاحية **Contents: Read and write** على المستودع |
| `GITHUB_REPO` | بصيغة `المالك/المستودع` |
| `GITHUB_BRANCH` | فرع البيانات، ويُنشأ تلقائيًا (الافتراضي `database`) |
| `COMMAND_PREFIX` | البادئة الافتراضية (الافتراضي `.`) |

> يُستحسن إبقاء فرع البيانات منفصلًا عن فرع الشيفرة، حتى لا تُطلق إيداعات البيانات إعادة نشر المشروع.

## الأوامر المدمجة

| القسم | الأوامر |
|---|---|
| الأساسية | `الاوامر` · `اوامر <قسم>` · `امر <اسم>` |
| النظام | `فحص` · `الحالة` · `اعادة تشغيل` · `البادئة` · `تغيير البادئة` · `القاعدة` · `حفظ القاعدة` · `بيانات <مجموعة>` |
| الإضافات | `الاضافات` · `تفعيل اضافة` · `تعطيل اضافة` · `اعادة تحميل اضافة` · `تثبيت اضافة` · `حذف اضافة` |
| الذاتية | `حفظ الذاتية` · `تفعيل الذاتية` · `تعطيل الذاتية` · `حالة الذاتية` |

يتجاهل المطابق التشكيل والفروق بين صور الألف، فتصحّ كتابة `.أوامر` و`.اوامر` معًا. ويجوز أن يتكوّن اسم الأمر من عدة كلمات، ويُفضَّل الاسم الأطول عند التطابق.

## كتابة إضافة

انظر `examples/plugin_template.py`. الحد الأدنى:

```python
from core import Plugin, runtime

plugin = Plugin(category="الذاتية", title="عنوان الإضافة", description="وصف موجز", order=10)

@plugin.command("اسم الأمر", usage="<وسيط>", description="وصف الأمر.")
async def handler(ctx):
    store = runtime.db.collection("my_plugin")   # يُحفظ في data/my_plugin.json بالمستودع
    await store.set("key", "value")
    await ctx.reply("تم التنفيذ.")
```

- يظهر الأمر تلقائيًا في قسم `category`؛ والإضافات التي تتشارك اسم القسم تُجمع في قسم واحد.
- `order` يحدّد ترتيب القسم (الأصغر أولًا).
- `@plugin.on(events.NewMessage(...))` لمعالجة أحداث تيليجرام، و`@plugin.startup` / `@plugin.shutdown` لدورة حياة الإضافة.
- **التثبيت أثناء التشغيل**: أرسل ملف الإضافة `.py` ثم ردّ عليه بالأمر `.تثبيت اضافة`؛ تُحمَّل فورًا وتُحفظ في `plugins/` ضمن فرع البيانات فتعود تلقائيًا عند كل تشغيل.

## الهيكل

```
main.py            نقطة التشغيل
core/              النواة: السجل، المحمّل، الموزّع، قاعدة البيانات، عميل GitHub
plugins/           الإضافات المدمجة
plugins_external/  الإضافات المثبّتة (تُزامَن من المستودع، ولا تُرفع إلى Git)
examples/          قالب إضافة
tools/             أداة توليد الجلسة
tests/             اختبار شامل دون اتصال
```

## ملاحظات مهمة

- **الأمان**: الإضافات المثبّتة تنفّذ شيفرة بايثون بصلاحيات حسابك، فلا تثبّت إلا ما تثق به. واحفظ `TG_SESSION` و`GITHUB_TOKEN` سرًّا؛ ولا تجعل المستودع عامًّا لأن البيانات قد تتضمن معلومات شخصية.
- **الحفظ**: تُجمَّع الكتابات وتُحفظ بعد نحو خمس ثوانٍ لتقليل الإيداعات، وعند فشل الاتصال تبقى في الذاكرة وتُعاد المحاولة تلقائيًا. وللحفظ الفوري: `.حفظ القاعدة`.
- **الحجم**: يُفضَّل ألا يتجاوز ملف المجموعة الواحدة بضعة ميغابايتات؛ قسّم البيانات الكبيرة على مجموعات.
- **الذاتية**: يعتمد حفظ الوسائط ذاتية التدمير على سماح تيليجرام بتنزيلها، وقد يتغير ذلك من جهته.
